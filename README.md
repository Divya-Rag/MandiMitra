# MandiMitra

आज का मंडी भाव, एक ही जगह

MandiMitra is a Hindi-first agricultural market intelligence platform designed to help farmers compare mandi prices, identify better selling opportunities, and make informed market decisions.

## Initial Focus

State:
- Uttar Pradesh

Crops:
- Wheat
- Rice
- Peas
- Moong

## MVP Features

- Daily mandi price updates
- Crop-wise price comparison
- Best mandi identification
- Price trend visualization
- Admin panel for price entry
